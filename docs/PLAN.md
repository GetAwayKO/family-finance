# План разработки Cash Flow

Приложение для учёта личных и семейных финансов: веб-клиент, мобильное приложение и отдельный сервер.

## Принятые решения

- **Сервер отдельный**: NestJS + PostgreSQL + Prisma, репозиторий `finance-server`.
- **Контракт API**: сервер публикует OpenAPI, клиенты генерируют из него типы.
- **Вход**: JWT (короткий access-токен) + refresh-токен с ротацией. Cookie-сессии не используем: они неудобны в мобильном приложении.
- **Мобильное приложение**: React Native (Expo), репозиторий `family-finance-mobile`.
- **Проверки доступа только на сервере.** Клиент получает только те данные, которые пользователю разрешено видеть.
- **Идентификаторы (UUID) создаёт клиент, повторная отправка не создаёт дублей.** Это задел под ввод операций без интернета.
- **Деньги** хранятся целыми числами в минимальных единицах валюты (`bigint`), без float.
- **Личные счета видны всей семье.** Владелец может скрыть детализацию.
- **Поддерживается несколько валют.**

## Модель данных

| Сущность               | Суть                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------- |
| User                   | пользователь                                                                           |
| Family                 | семья с общим бюджетом, основная валюта                                                |
| Membership             | пользователь в семье, роль `owner` / `member`                                          |
| Account                | счёт (наличные, карта, вклад). Владелец — пользователь или семья; валюта; `visibility` |
| Category               | категория дохода или расхода, вложенная, общая для семьи                               |
| Transaction            | доход, расход или перевод: сумма, дата, счёт, категория, автор, комментарий            |
| Budget                 | лимит по категории на месяц, в основной валюте семьи                                   |
| ExchangeRate           | курс на дату: из какой валюты, в какую, курс                                           |
| RecurringPayment, Goal | регулярные платежи и цели накоплений                                                   |

### Видимость личных счетов

`visibility` у счёта:

- `full`: семья видит остаток и все операции;
- `summary`: семья видит остаток и общие суммы за период, без списка операций.

Для чужого счёта с `summary` сервер:

- отклоняет запрос списка его операций и не включает их в общий семейный список;
- показывает его доходы и расходы в семейных итогах одной строкой «Личные (скрыто)», без разбивки по категориям;
- в переводе между скрытым и общим счётом показывает семье только сумму перевода на стороне общего счёта.

### Валюты

- У каждого счёта своя валюта (ISO 4217). Сумма операции хранится в валюте счёта. Число знаков после запятой берётся из валюты (у RUB 2, у JPY 0).
- Перевод между счетами в разных валютах хранит обе суммы: списанную и зачисленную.
- Отчёты пересчитываются в основную валюту семьи по курсу на дату операции, общий баланс — по текущему курсу.
- `ExchangeRate` заполняется раз в день из внешнего источника (например, API ЦБ РФ).
